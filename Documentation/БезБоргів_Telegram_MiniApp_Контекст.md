# «БезБоргів» — Telegram Mini App

Передай цей документ у новий чат як контекст. Тут зібрано все,
що потрібно для старту розробки Telegram Mini App версії
iOS-застосунку «БезБоргів».

---

## Що таке «БезБоргів»

iOS-застосунок для відслідковування особистих кредитів. Мова:
українська, валюта: UAH (грн). Застосунок вже існує (Swift +
SwiftUI + SwiftData, iOS 17+). Завдання — зробити повну копію
як Telegram Mini App.

## Функціонал (що має робити Mini App)

КРЕДИТИ:
- Додавання кредиту у двох сценаріях: «Новий» і «Вже плачу»
  (кредит, що додається посередині — вводиться залишок і
  кількість платежів, що залишились)
- Два режими: «Я знаю ставку» (застосунок рахує платіж за
  формулою ануїтету) і «Я знаю суму платежу» (застосунок
  рахує ставку через IRR)
- Ставка 0% дозволена (розстрочка)
- Редагування кредиту (при зміні ставки — внесені платежі не
  змінюються, графік майбутніх перераховується)
- Видалення з підтвердженням
- Архівація (при залишку 0 — пропонується архівувати) і
  розархівація

ПЛАТЕЖІ:
- Фіксація вручну (кнопка «Оплачено»)
- Підставляється рекомендована сума (за стратегією) або планова
- Можна відредагувати суму (переплата/недоплата)
- Дата заднім числом дозволена
- Позаплановий (додатковий) платіж — окрема кнопка
- Дострокове погашення завжди зменшує термін (не платіж)
- Редагування і видалення платежу з історії — з перерахунком
  залишку і графіка
- Прострочення: статус з наступного дня, без пені

ГОЛОВНИЙ ЕКРАН:
- Загальний борг (тіло + відсотки, загальна сума по всіх
  кредитах)
- Мінімальні і рекомендовані платежі на місяць
- Блок «Залишилось цього місяця» — рахується від мінімальних
  платежів, будь-який платіж зменшує, скидається щомісяця
- Список кредитів за датою наступного платежу
- Картка: назва, залишок, прогрес-бар, платіж, дата, кількість
  платежів
- Прострочені — червоним з бейджем
- Банер «Оберіть стратегію» якщо не обрана
- Тап на «Загальний борг» → екран з інфо + кнопка «Календар»

ДЕТАЛІ КРЕДИТУ:
- Залишок, прогрес-бар, наступний платіж, дата
- Блок прогнозу закриття (за графіком / за стратегією)
- Два таби: «Графік платежів» і «Фактичні оплати»
- Кнопки: Внести платіж, Дострокове погашення

СТРАТЕГІЯ ПОГАШЕННЯ:
- Дві стратегії: «Лавина» (рекомендована) і «Сніжний ком»
- Бюджет на місяць (опціональний, включно з обов'язковими)
- План на місяць: скільки на який кредит
- Ефект: «на N місяців раніше» + дата закриття всіх кредитів
- Попередження якщо бюджет < мінімальних платежів
- Перебудова плану після кожної зміни
- Флоу: онбординг-попап → введення бюджету → анімація
  «Підбираємо стратегію» 1.5-3 сек → результат

КАЛЕНДАР ПЛАТЕЖІВ:
- Два місяці горизонтально (2 колонки)
- Скрол тільки вперед, до 20 років
- Кольорові мітки кредитів (палітра 8-10 кольорів)
- Статуси: зелена галочка (сплачено), колір кредиту
  (майбутній), оранжевий (прострочено)
- Макс 3 мітки на день + «+N»
- Тап на день: 1 кредит → деталі, кілька → список
- Список платежів під календарем — завжди поточний місяць

НОТИФІКАЦІЇ:
- У Telegram замість push — нагадування через бота
  (бот пише повідомлення в чат)
- За 3 дні, за 1 день, в день платежу (глобальне налаштування)
- Щоденне нагадування про прострочення
- Текст: назва кредиту + сума

ПОПЕРЕДЖЕННЯ ПРИ ПЛАТЕЖІ:
- Якщо менше за мінімальний: «Термін збільшився на N міс.»
- Якщо менше за рекомендований: мотиваційне повідомлення
- N = різниця з попереднім прогнозом

## Бізнес-логіка розрахунків (критично — портувати точно)

АНУЇТЕТНИЙ ПЛАТІЖ:
i = річна_ставка / 12 / 100  (місячна ставка)
A = S * i / (1 - (1 + i)^(-n))  (щомісячний платіж)
Якщо ставка = 0%: A = S / n

Розбивка кожного платежу:
відсотки_k = залишок_(k-1) * i
тіло_k = A - відсотки_k
залишок_k = залишок_(k-1) - тіло_k

ОСТАННІЙ ПЛАТІЖ: коригується щоб залишок = 0.00 рівно

IRR (розрахунок ставки з відомого платежу):
Дано S, n, A. Бісекція або Ньютон для знаходження i з:
A = S * i / (1 - (1+i)^(-n))
Якщо A * n = S → ставка = 0%
Якщо A * n < S → помилка

ДАТИ ПЛАТЕЖІВ:
День платежу = число з дати першого платежу
Якщо число > днів у місяці → останній день місяця
(31 у лютому → 28/29)

ВСІ РОЗРАХУНКИ: тільки Decimal (не float), округлення
half-up до 2 знаків

SINGLE SOURCE OF TRUTH: фактична історія платежів.
Графік майбутніх обчислюється on-the-fly, не зберігається.

## Технічний стек для Telegram Mini App

BACKEND:
- Python 3.11+
- FastAPI (REST API для фронтенду)
- aiogram 3.x (Telegram Bot API — нагадування)
- SQLAlchemy + Alembic (ORM + міграції)
- PostgreSQL (основна БД)
- APScheduler або Celery (планувальник нагадувань)

FRONTEND:
- React 18 + TypeScript
- Tailwind CSS (стилізація)
- Telegram Web App SDK (@twa-dev/sdk)
- Vite (збірка)
- Decimal.js (грошові розрахунки на фронті — ніколи float)

ХОСТИНГ (безкоштовний для старту):
- Backend: Railway (free tier: 500 годин/міс) або Render
  (free tier з обмеженнями)
- БД: Railway PostgreSQL (free tier: 1GB) або Supabase
  (free tier: 500MB)
- Frontend: Vercel або Cloudflare Pages (безкоштовно)
- Коли виростеш: Hetzner VPS (~$4-6/міс) або Railway Pro
  ($5/міс)

БОТ (TELEGRAM):
- Створити через @BotFather
- Отримати Bot Token
- Налаштувати Web App URL (кнопка в боті → Mini App)
- Бот також надсилає нагадування (замість push)

## Архітектура

Telegram App (React)
    ↕ REST API (HTTPS)
Backend (FastAPI)
    ↕ SQLAlchemy
PostgreSQL
    ↕
APScheduler → aiogram → Telegram Bot API → нагадування

Авторизація: Telegram передає initData при відкритті Mini App.
Backend валідує підпис (HMAC-SHA256 з Bot Token) — і знає, хто
користувач. Без логіну/паролю.

## Що є з iOS, що можна перевикористати

ДОКУМЕНТИ (покласти в docs/ нового проєкту):
- SRS (повна специфікація з формулами і вимогами)
- User Stories + AC + тест-кейси TC-CALC-01..13

ТЕСТ-КЕЙСИ — портувати на Python (pytest):
Усі TC-CALC-01..13 з конкретними числами і очікуваними
значеннями. Це найцінніше — покриває всю математику.

БІЗНЕС-ЛОГІКА — портувати з Swift на Python:
LoanCalculator (ануїтет, IRR, перерахунок, дати) →
loan_calculator.py
StrategyPlanner (Лавина, Сніжний ком, симуляція) →
strategy_planner.py

НЕ портувати (зробити з нуля):
- UI (React замість SwiftUI)
- Зберігання (PostgreSQL замість SwiftData)
- Нотифікації (Telegram Bot замість iOS push)
- Навігація (React Router замість NavigationStack)

## Важливі правила

- Усі грошові розрахунки ТІЛЬКИ Decimal, ніколи float
- Формули з SRS — єдине джерело правди для математики
- Тести TC-CALC-01..13 мають проходити і на Python-версії
- Мова інтерфейсу: українська
- Валюта: UAH (грн), формат: 1 000,00 ₴ (пробіл між тисячами,
  кома для копійок)
- Дати: локальна таймзона користувача, формат «6 лютого 2028 року»
- Українські відмінювання: 1 місяць / 2-4 місяці / 5+ місяців
